# iPhone Mockup Studio

Una aplicación web sencilla para crear mockups visuales de iPhone.

## Funciones
- Vista previa en tiempo real de varios modelos de iPhone.
- Acabados y fondos de pantalla personalizables.
- Carga de una imagen propia para la pantalla.
- Título y subtítulo editables.
- Exportación del diseño como PNG.
- Interfaz adaptable a móvil y escritorio.

## Ejecutar en local
1. Instala Node.js.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta \`npm install\`.
4. Ejecuta \`npm run dev\`.

## Privacidad
Las imágenes seleccionadas se procesan en el navegador y no se envían a un servidor.

## Nota
Los modelos son representaciones visuales para mockups y no una herramienta oficial de Apple.
